# Workout Video Library

Purpose: keep a small, durable set of verified exercise demos that can be reused when presenting the current workout plan.

**Usage rule:** when a workout is presented and the user asks for videos, prefer the links in this file instead of inventing or recalling a URL from memory. If a planned movement is not covered here, verify a reputable demo before linking it, then add it here if useful.

**What "verified" means here:** the link was manually checked on 2026-08-08 to confirm that it resolves to the named movement/demo and comes from a physical-therapy, established fitness-education, or established calisthenics source. This is verification of the link and movement match, not an endorsement of every cue or claim made by the creator.
